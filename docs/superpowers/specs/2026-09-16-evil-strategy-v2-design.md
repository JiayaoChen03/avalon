# 双邪恶 Agent 混合策略 v2

依据用户提供的 v2 任务说明实现：代码决定战略和结构化行动，LLM 只表演当前战术。先完成 P0，并实现七种模式需要的公开信号、有限叙事和 Merlin 概率基础；人格权重和 LLM 策略提案属于后续扩展。

## 数据边界

Game 保持最终规则权威。每局唯一 EvilStrategyManager 只获得玩家 ID、两个邪恶 ID 和公开事件，不接收完整角色表、真正的 Merlin 身份或他人的私有 LLM 输出。两个邪恶 Agent 共享该对象；善良 Agent（包括 Merlin）不能绑定它。

EvilSharedState 由代码维护嫌疑、信任、配对嫌疑、公开行为标签、Merlin 概率、角色分工、模式、目标、牺牲对象、失败票负责人和最多四条有真实事件依据的竞争性叙事。状态跨任务轮保存，不跨对局保存。

## 决策

模式采用局势评分加少量独立随机扰动；固定 seed 可复现，不能按轮次写死剧本。主要阶段重新评估；同一次重试复用完全相同的战术和上下文。Aggressor/Sleeper 在初始分工和局势差异足够大时动态分配。

高配对嫌疑、连续同票、过多保护或共同被怀疑提高 Fake Conflict；强度在 0–1 内变化。高嫌疑成员且队友安全可信时可进入 Sacrifice，目标是保全队友和误导推断，不能自爆身份。

Manager 控制邪恶 AI 的队伍、投票、任务牌和刺杀目标。任务规则仍为本项目 5/6 人局的一张 FAIL 即失败；双邪恶任务至多一名 AI sabotage。人类邪恶玩家保留操作权：先收其秘密任务牌，再协调 AI，已有 FAIL 时 AI 不追加失败票。

## LLM

善良 Agent 保留原协议；受策略管理的邪恶 Agent 使用精简协议 `{social: {card,target,reason,statement,rationale,evidence}}`，不能返回角色、概率或战略覆盖。动态上下文只有当次角色分工、主目标、最多一个次目标、目标玩家、必要伙伴信息、有限事件和叙事及已确定的行动。

LLM 生成自然中文和简短公开理由。严格校验卡牌/目标、公开事件引用以及显式私有战术泄漏；无效结果走现有重试，无静态台词或 mock 代替。可检测的字段、模式名称和身份自报被阻止；任意自然语言隐喻泄漏不能由规则检测器完全保证。

## 终端与验证

默认正常游戏输出不含战略信息。`--debug-strategy` 输出到开发者 stderr，`--strategy-log` 保存独立结构化 JSONL；永不写入 Game.events、公开日志或善良上下文。每项真实动作留下结构化 StrategyDecision，不保存 CoT。

验证共享权限、角色分工、Fake Conflict/Sacrifice 情景、单失败票、人类任务牌、七种模式、固定随机性、重试不重抽、LLM 越权、引用依据、私有输出隔离、完整 CLI 及现有 Avalon 规则。
