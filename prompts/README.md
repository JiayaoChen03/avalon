# 角色提示词

[`corrupted_castle_system.md`](corrupted_castle_system.md) 是可直接用作 system 消息正文的中文提示词，统一约束世界观、个人求生动机和角色对话。适用于主角团的每位角色，具体身份、经历、公开历史和当前行动由调用时的上下文提供。

游戏现在默认加载这份提示词。启动 `python -m avalon` 或 `avalon` 时，会显示 `[WORLD] 腐化城堡`；普通、Merlin 和邪恶角色的每次真实模型请求都会包含它。

`avalon/llm.py` 将完整场景正文、简短的世界内用语说明，以及该角色适用的 JSON 协议组合为 system 消息。原有提示词中以阵营胜利作为人物动机的表述已替换。名单、卡牌、公开证据校验和邪恶协调仍由现有代码控制，Avalon 胜负结算保持现状；库存、伤势和个人存活结算尚未新增。

源码或 editable 安装使用本目录的文件，与启动时所在目录无关。每局开始读取一次，后续回合和失败重试使用同一份内容；修改文件后重新启动游戏即可生效。普通安装会携带相同的场景文件。文件缺失、空白或不是有效 UTF-8 时会报错停止，不退回旧场景。公开或私有日志不能覆盖正在使用的提示词。

公开台词触发身份泄露检查时，会按现有重试设置重新请求模型生成；耗尽重试才停止，不使用固定替代台词。邪恶角色仍额外检查私有战术信息。

场景文件中的背景属于固定设定；某次外出的收获、某人的伤势、某处是否出现威胁等具体事实，都应来自宿主上下文，不能由角色即兴编造成已确认事件。
